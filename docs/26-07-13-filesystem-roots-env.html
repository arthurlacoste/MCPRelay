Racines filesystem configurables

Date : 13 juillet 2026.

Travail réalisé

La racine codée en dur a été remplacée par MCP_FILESYSTEM_ROOTS.

Plusieurs dossiers sont acceptés. Le séparateur est : sur macOS/Linux et ; sur Windows.

Sans variable, l’accès couvre la racine du volume : / sur macOS/Linux.

Pourquoi

Éviter un chemin utilisateur dans le code. Permettre une configuration locale sans modifier les sources.

Risques et contexte

Chaque racine donne aux outils filesystem un accès en lecture et écriture. Le défaut / expose tout ce que le compte système peut lire ou modifier.

Un redémarrage de MCPRelay est requis après modification de config/.env.

Axes de progression

  1. Valider au démarrage que chaque racine existe.
  2. Refuser les racines trop larges avec une option de sécurité stricte.
  3. Afficher les racines actives dans un outil de diagnostic.
  4. Ajouter un test de démarrage Windows dans la CI.
